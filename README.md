# [Shelter]([https://shelter-lemon.vercel.app/](https://landing-page-shelter.netlify.app/))

Pet shelter landing page. Project structure follows Feature-Sliced Design (FSD).

## Features

- Animals carousel
- Modals
- Burger menu
- Pagination
- Mobile layout

## Tech Stack

- React
- Vite
- React Router
- TypeScript
- Sass
- Prettier
- ESLint
- Stylelint
- Vercel

## How to use

Requires Node.js 24.15+ (24.x) or 26+ and npm 11+.

1. Clone the repo

```bash
git clone https://github.com/SavitskayaKseniya22/shelter.git
```

2. Change directory

```bash
cd shelter
```

3. Install dependencies

```bash
npm ci
```

4. Start the dev server

```bash
npm run dev
```

Open http://localhost:5173.

Run `npm run check` to check formatting, code, styles and the build. Use `npm run build` to build the site into `dist/` and `npm run preview` to preview it locally.
